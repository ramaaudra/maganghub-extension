# Popup adopts a Field-Notebook identity (shadcn-svelte preset "sera"), superseding the "mirror MagangHub" aesthetic

ADR-0004 chose Svelte + shadcn-svelte + Tailwind for the popup and stated, as a supporting reason, that "shadcn-svelte is used in the popup specifically to match MagangHub's own shadcn/Tailwind aesthetic so the popup feels native." This ADR keeps the stack decision (Svelte + shadcn-svelte + Tailwind, plain DOM in the content script) intact, but **supersedes the "match MagangHub's aesthetic" commitment** for the popup. The popup now carries its own identity via the `b3ax5EJfHM` preset (shadcn-svelte style **"sera"**): one calm blue accent (`oklch(0.5 0.134 242.749)`, Field Blue), sharp corners (`--radius: 0rem`), Geist Variable as the sole typeface, and flat depth. `DESIGN.md` and `.impeccable/design.json` are the normative source for that identity.

The reason for the shift is product, not fashion. PRODUCT.md principle 4 ("feel native to MagangHub") was read as an aesthetic instruction, but the deeper commitment is *trust by construction*. A popup that mimics the host site's look reads as part of the site; a popup that reads as a plainly different instrument — a field notebook sitting beside the site — makes the credential-free, local-first posture legible at first glance. The blue is rare on purpose (≤10% of any screen, used only for the active Lowongan, the exit link, and focus), the sharp corners and single typeface read as deliberately chosen rather than inherited, and the absence of a filled primary button is a visible statement that this tool does not perform actions on the user's behalf. Mirroring MagangHub would have made the extension *invisible*; the Field-Notebook identity makes it *trustworthy*.

The non-obvious part is what is **not** changed. The content-script star toggle still mirrors MagangHub's "Bagikan" geometry (40×40, 14px radius, 1px `#e1e7ef` border, white background) per ADR-0004, deliberately **not** the popup's sharp rectangle. The content script ships no framework runtime, no shadcn-svelte, no DESIGN.md tokens — that split is the load-bearing decision of ADR-0004 and stays. This ADR only moves the popup from "imitate the host" to "be a distinct, trustworthy counterpart." A future contributor may be tempted to push the new identity into the injected toggle for consistency; that is the rejected alternative: consistent, but it breaks the rule that injected UI must read as a missing feature of the page, not as a foreign overlay.

Consequences: `DESIGN.md` and `.impeccable/design.json` now describe the popup's visual system and must be kept in sync as the popup grows (re-run `/impeccable document` after token changes). Adding more shadcn-svelte components to the popup uses the "sera" style and the `@/lib/components/ui` alias recorded in `components.json`. If the project later re-commits to mirroring MagangHub, both this ADR and the preset must be revisited together — the Field-Notebook identity and the preset are one decision, not two.
